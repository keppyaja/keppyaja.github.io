01 / Tentang

Di balik alias Skipped.

Saya Tsaqif, atau biasanya dipanggil Sukep, mahasiswa Sarjana Terapan Teknik Informatika di Politeknik Elektronika Negeri Surabaya. Minat saya ada di kriptografi, binary exploitation, dan web exploitation.

Saya berlatih lewat CryptoHack, picoCTF (sekarang CyLab), dan OverTheWire. Kali Linux dan WSL menjadi lingkungan kerja saya sehari-hari.

Di luar CTF, saya mengerjakan soal algoritma di Codeforces dengan C++ dan C, serta mengerjakan proyek kecil di GitHub, dan belajar merancang basis data relasional menggunakan PostgreSQL maupun MySQL.
