# Write-Ups

## About

So, this is my repository to archive all of my the write up for some CTF Challenges that me/my team can solve. Alright, that's all from me.

## Archive Structure

- `pwn/` or `binex/` - Exploitation challenges and binary analysis write-ups.
- `Web/` or `Web-Explot/` - Web application security challenges and web exploit write-ups.
- `Crypto/` or `Cryptography/` - Cryptography challenges and cipher analysis write-ups.
- `Reverse-Engineering/` - Reverse engineering and binary reversing write-ups.
- `Forensics/` - Digital forensics challenges and forensic analysis write-ups.
- `Misc/` - Miscellaneous challenges that don't fit other categories or jsut 4 fun challenges.
- `General/` - This only applied on CyLab with category General Skills
- `Blockchain/` - Blockchain and smart contract challenges, cryptocurrency analysis, and distributed ledger write-ups. 

## Contribution

Add new write-ups by creating a new markdown file in the relevant directory and summarizing the challenge, approach, and solution.
