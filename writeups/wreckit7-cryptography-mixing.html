Deskripsi Challenge

ICE MIXED PAKDE NYOS THIS MIXED FRUIT AND SYRUP IS NOT MEASURED, THE PORTION IS VERY BIG

Analisis

Script challenge membangun kurva elips y^2 = x^3 + A*x + B mod P. Flag diletakkan pada koordinat y1 dari titik (x1, y1) di kurva, lalu koordinat tersebut di-double sebanyak 5 kali. Output yang diberikan hanyalah enam nilai x.

#!/usr/bin/env python3
from secrets import flag
import os
from Crypto.Util.number import getPrime


P = getPrime(512)
while P % 4 != 3:
    P = getPrime(512)


A = int.from_bytes(os.urandom(64), 'big') % P
Y1 = int.from_bytes(flag.ljust(64, b'\x00'), 'big')
X1 = int.from_bytes(os.urandom(64), 'big') % P
B = (Y1**2 - X1**3 - A*X1) % P
X = [X1]
for _ in range(5):
    curr_X = X[-1]
    num = (curr_X**2 - A)**2 - 8*B*curr_X
    den = 4*(curr_X**3 + A*curr_X + B)
    next_X = (num * pow(den, -1, P)) % P
    X.append(next_X)


with open("out.txt", "w") as f:
    f.write("data = " + repr(X))

Nilai P dan A dibangkitkan secara acak, sedangkan B dihitung dari Y1, X1, dan A. Karena Y1 berisi flag, kita perlu memulihkan P, A, dan B hanya dari deretan nilai x.

Solve

Rumus doubling di atas bersifat publik. Setiap pasangan (x1, x2) yang berurutan memberikan satu persamaan yang melibatkan A, B, dan P:

x2 * 4*(x1^3 + A*x1 + B) = (x1^2 - A)^2 - 8*B*x1 (mod P)

Kalau dipindah ke satu ruas dan didefinisikan:

c1 = 4*x1*x2 + 2*x1^2
c2 = 4*x2 + 8*x1
c3 = 4*x2*x1^3 - x1^4

Maka setiap pasangan (x1, x2) yang berurutan memberikan:

Eq_i: A^2 - c1_i*A - c2_i*B - c3_i = 0 (mod P)

Koefisien A^2 sama untuk semua pasangan, jadi bisa diabaikan dengan mengurangkan dua persamaan:

D_i = Eq_i - Eq_{i+1}: d1_i*A + d2_i*B + d3_i = 0 (mod P)

Dari sini kita memperoleh empat persamaan linear murni dalam A dan B. Untuk mencari P, kita bisa memakai GCD determinan. Ambil tiga persamaan untuk membentuk matriks 3×3:

| d1_a d2_a d3_a |
| d1_b d2_b d3_b |
| d1_c d2_c d3_c |

Karena ketiganya memiliki solusi yang sama (A, B, 1) modulo P, determinan matriks tersebut harus habis dibagi P. Hasilnya adalah prima 512-bit yang tepat.

Setelah P diketahui, kita tinggal mencari A dan B. Untuk mendapatkan flag:

val = X1^3 + A*X1 + B (mod P)

Karena P % 4 == 3, akar kuadratnya dapat dihitung dengan:

y = val^((P+1)//4) (mod P)

def c123(i, mod=None):
    """Koefisien c1, c2, c3 untuk persamaan Eq_i: A^2 - c1*A - c2*B - c3 = 0"""
    x1, x2 = x[i], x[i + 1]
    c1 = 4 * x1 * x2 + 2 * x1 ** 2
    c2 = 4 * x2 + 8 * x1
    c3 = 4 * x2 * x1 ** 3 - x1 ** 4
    if mod:
        return c1 % mod, c2 % mod, c3 % mod
    return c1, c2, c3


def build_D():
    """Bangun daftar persamaan linear D_i: d1*A + d2*B + d3 = 0 (mod P)
    dari selisih Eq_i - Eq_{i+1} (menghilangkan A^2)."""
    C = [c123(i) for i in range(n - 1)]
    D = []
    for i in range(len(C) - 1):
        c1a, c2a, c3a = C[i]
        c1b, c2b, c3b = C[i + 1]
        d1 = -(c1a - c1b)
        d2 = -(c2a - c2b)
        d3 = -(c3a - c3b)
        D.append((d1, d2, d3))
    return D


def recover_P(D):
    """Cari P via GCD determinan 3x3 dari kombinasi baris D, lalu buang
    faktor kecil supaya tersisa 512-bit prime P % 4 == 3."""
    dets = []
    for combo in combinations(range(len(D)), 3):
        rows = [D[i] for i in combo]
        det = Matrix(rows).det()
        dets.append(int(det))
    g = 0
    for d in dets:
        g = math.gcd(g, d)
    n_ = abs(g)
    small = 1
    for p in range(2, 200_000):
        while n_ % p == 0:
            n_ //= p
            small *= p
    assert isprime(n_), "Gagal mendapatkan P prima, cek data/metode"
    assert n_.bit_length() >= 500, "P terlalu kecil, mungkin salah kombinasi"
    return n_


def recover_AB(D, P):
    """Selesaikan sistem linear A, B mod P memakai 2 persamaan pertama,
    lalu verifikasi dengan sisa persamaan."""
    D = [(d1 % P, d2 % P, d3 % P) for d1, d2, d3 in D]
    (d1_1, d2_1, d3_1), (d1_2, d2_2, d3_2) = D[0], D[1]
    det = (d1_1 * d2_2 - d1_2 * d2_1) % P
    detA = ((-d3_1) * d2_2 - (-d3_2) * d2_1) % P
    detB = (d1_1 * (-d3_2) - d1_2 * (-d3_1)) % P
    inv_det = pow(det, -1, P)
    A = (detA * inv_det) % P
    B = (detB * inv_det) % P
    for d1, d2, d3 in D:
        assert (d1 * A + d2 * B + d3) % P == 0
    c1, c2, c3 = c123(0, mod=P)
    assert (A * A - c1 * A - c2 * B - c3) % P == 0, "Verifikasi A,B gagal"
    return A, B


def recover_flag(P, A, B):
    assert P % 4 == 3
    x1 = x[0]
    val = (x1 ** 3 + A * x1 + B) % P
    y = pow(val, (P + 1) // 4, P)
    for cand in (y, P - y):
        b = cand.to_bytes(64, 'big').rstrip(b'\x00')
        try:
            s = b.decode()
            if s.isprintable():
                return s
        except UnicodeDecodeError:
            continue
    return None


def main():
    D = build_D()
    P = recover_P(D)
    print(f"[+] P ditemukan ({P.bit_length()} bit, P%4={P % 4}):")
    print(f"      {P}")
    A, B = recover_AB(D, P)
    print(f"[+] A = {A}")
    print(f"[+] B = {B}")
    flag = recover_flag(P, A, B)
    print(f"[+] FLAG: {flag}")


if __name__ == "__main__":
    main()
